# March 2026 release notes

Changes merged between 2026-03-01 and 2026-03-31. This is not a complete list: it covers selected user-facing changes that are still in the current release.

---

- **Progress notes — Wound care progress note generator.** Medipyxis builds the wound care progress note from the visit's documentation. (PR #1487, #1520, #1542)
- **Visit documentation — Previous treatments section added.** (PR #1486, #1530) _Update (Nov 2026):_ it is now the **Medical Necessity & Previous Treatments** section of the Visit Wizard.
- **Scheduling — Each appointment stores its time slot.** (PR #1497, #1501)

Later changes are in the [April 2026 release notes](/release-notes/2026-04/).
