# January 2026 release notes

Changes merged between 2026-01-01 and 2026-01-31. This is not a complete list: it covers selected user-facing changes that are still in the current release.

---

- **Medical history — Family history records can be edited.** (PR #1335, #1343)
- **Referral Intake — TIFF images can be uploaded** to a referral's documents. (PR #1320, #1323)
- **Voice intake — A voice intake button was added to the microphone control.** (PR #1342)

Later changes are in the [February 2026](/release-notes/2026-02/), [March 2026](/release-notes/2026-03/), and [April 2026](/release-notes/2026-04/) release notes.
