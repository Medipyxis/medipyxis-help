# September 2026 release notes

Changes to the progress note and the documentation checklist, shipped on 2026-09-18. Items are grouped by module. Entries marked ★ are high-impact or frequently requested.

Full guide: [How your progress note is written](/modules/visit-wizard-ehr/progress-note/).

---

## Documents & Progress Notes

- ★ **Progress Notes — Sentences the software wrote for you were removed.** The note no longer supplies default wording for allergies, debridement, pressure-injury prevention plans, same-day E/M, medical necessity, homebound status, or patient education. What a blank field prints depends on the section:
  - Blank drug allergy and latex/adhesive rows, blank debridement detail rows, and a blank same-day E/M justification print "Not documented."
  - A blank pressure-injury prevention plan, medical-necessity note, or homebound justification is left out of the note.
  - A fully blank patient-education section prints "Patient education not documented this visit."
  - If you leave the debridement procedure narrative empty, the procedure summary from the Procedures screen prints in its place.

- ★ **Progress Notes — Two debridement rows removed, one rebuilt.** "Pathology sent" and "Post-procedure dressing" no longer appear. No screen ever asked for them, so every debridement note was answering them on the patient's behalf. "Tissue present (pre-procedure)" still appears, but it now comes from this visit's wound-bed assessment; when the wound bed was not assessed this visit, it prints "Not documented."
- ★ **Progress Notes — Six incorrect Medicare policy citations removed.** Three referenced policies that do not govern this service — tracheostomy supplies, seat-lift mechanisms, and surgical dressings supplied as DME — and three cited policy numbers that do not exist. Citations now come from a table of policies checked against the Medicare Coverage Database. The note cites only the policy for the patient's Medicare contractor (debridement for Novitas, WPS, and CGS; skin substitutes for Novitas, First Coast, and CGS) and prints no citation when that contractor has no checked policy.
- **Progress Notes — Preview matches the stored file.** The review screen shows the actual PDF that will be stored, rather than a separate on-screen version of it.
- **Addendum — Fabrication remediation checklist extended.** When you add an addendum from a wound's detail page and choose **Fabrication remediation**, a checklist now names each class of written-in sentence that was removed, so an older signed note can be corrected precisely.

## Visit Wizard / EHR

- ★ **Documentation checklist before the note is created.** Once billing codes are staged, the Billing step shows how many documentation items are open, with a **Resolve** link. The list also opens when you press Continue to Review with items open. It shows what is missing, which wound it concerns, and a button that goes straight there. Items you can answer in a sentence open a box with the facts already documented and an example to adapt; you can dictate instead of typing. Every item is advisory and none of them block signing.
- ★ **Medical necessity question on home visits.** On a home visit (place of service 12, 13, or 14) with an E/M code staged and no necessity documented, the checklist asks why the patient needed a clinician today, rather than generating the narrative. Your answer prints with a label showing whether you wrote it yourself (typed or dictated) or started from the example. A separate item, on any visit, flags a wound necessity note that repeats that wound's previous visit word for word.
- **Acknowledgement when continuing past a billing-relevant item.** Choosing **Continue anyway** on an item that affects what can be billed — a debridement missing required elements, or a billed code with no documented wound — asks you to tick a box confirming you understand.
- **New-patient code warning fixed.** A check was running against an empty form and telling clinicians to use a new-patient code for patients who were already established.
