# September 2026 release notes

Changes to the progress note and the documentation checklist, shipped on 2026-09-18. Items are grouped by module. Entries marked ★ are high-impact or frequently requested.

Full guide: [How your progress note is written](../modules/visit-wizard-ehr/progress-note.md).

---

## Documents & Progress Notes

- ★ **Progress Notes — The note prints only what you documented.** Sentences the software used to supply on your behalf have been removed. Where a field is blank the note now says "Not documented."; where you wrote something, it prints exactly what you wrote. This affects allergies, debridement, pressure-injury prevention plans, same-day E/M, medical necessity, homebound justification, and patient education.
- ★ **Progress Notes — Three debridement rows removed.** "Pathology sent", "Tissue present pre" and "Post-procedure dressing" no longer appear. No screen ever asked for them, so every debridement note was answering them on the patient's behalf.
- ★ **Progress Notes — Six incorrect Medicare policy citations removed.** Three referenced policies that do not govern this service — tracheostomy supplies, seat-lift mechanisms, and surgical dressings supplied as DME — and three cited policy numbers that do not exist. The two verified wound-care policies remain.
- **Progress Notes — Preview matches the stored file.** The review screen shows the actual PDF that will be stored, rather than a separate on-screen version of it.
- **Addendum — Reason list extended.** The addendum reason list now names each class of written-in sentence that was removed, so an older signed note can be corrected precisely. See [Sign Off](../modules/visit-wizard-ehr/sign-off.md).

---

## Visit Wizard / EHR

- ★ **Documentation checklist before the note is created.** Staging billing codes opens a list of anything a Medicare reviewer would look for: what is missing, which wound it concerns, and a button that goes straight there. Items you can answer in a sentence open a box with the facts already documented and an example to adapt; you can dictate instead of typing. Every item is advisory and none of them block signing.
- ★ **Medical necessity asked once per visit.** The wizard asks why the patient needed a clinician, rather than generating the narrative. Your answer prints with a label showing whether you typed it, dictated it, or adapted an example. A separate item flags a wound necessity note that repeats the previous visit word for word.
- **Acknowledgement when continuing past a billing-relevant item.** Choosing **Continue anyway** on an item that affects what can be billed — a debridement missing required elements, or a billed code with no documented wound — asks you to tick a box confirming you understand.
- **New-patient code warning fixed.** A check was running against an empty form and telling clinicians to use a new-patient code for patients who were already established.
