Pull Codes suggests the visit code for where the visit happened

Video to be recorded on the demo system (demo data only) before this entry is published.

What you're seeing

  • For a visit at a nursing facility (place of service 31 or 32), Pull Codes suggests the visit code from the nursing facility code family.
  • For a visit at the patient's home or residence (place of service 12, 13, 14, 33 or 55), it suggests the code from the home visit family.
  • Office visits, and visits with no place of service, get the same office code as before.

Why it matters

The suggested visit code matches the setting, so the biller has less to correct by hand. The suggestion is a starting point: you still review every code before signing.

Next update Patients

Quick Add keeps the insurance you type

Video to be recorded on the demo system (demo data only) before this entry is published.

What you're seeing

  • Adding a new patient with Quick Add and typing in their insurance.
  • The patient's chart then shows that plan as their primary insurance, marked as not yet verified.
  • If the plan can't be saved, the patient is still saved and a message tells you to add the plan on the chart.

Why it matters

Before this update, the insurance typed in Quick Add was not kept, so the claim for that visit had no payer. Now the plan follows the patient from the first visit.

Next update Visit Wizard billing

Pulled codes stay on the wound cards

Video to be recorded on the demo system (demo data only) before this entry is published.

What you're seeing

  • Clicking Pull Codes and seeing the codes fill the wound cards.
  • The codes stay there. The button then reads Re-pull Codes.
  • If you change the wounds after pulling, a banner tells you the codes may be out of date.

Why it matters

Some visits showed "Pulled 3 codes" while the cards stayed empty, because a check running in the background cleared them a few seconds later. Now the codes you pull are the codes you review and sign.

Next update Notifications

Alerts arrive by email as well as in the bell

Video to be recorded on the demo system (demo data only) before this entry is published.

What you're seeing

  • An alert in the bell at the top of the app, and the same alert arriving by email.
  • Settings → Notifications, where Pause Alerts keeps alerts in the bell only.
  • Text messages show as Coming soon.

Why it matters

You hear about things that need you even when Medipyxis isn't open. If you chose to pause alerts, that choice is kept. Team chat messages stay in the app and are not emailed.
