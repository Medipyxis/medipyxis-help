How does a patient import fill in a one-line address?

whats-new Patients Updated 2026-11-27

When a patient file lists the address on one line, the import fills in the street, city, state and ZIP on the new chart, and tidies the ZIP to 62999-0001.

What happens when the address is on one line?

No sound · 66 seconds (half speed) · a text description of the video is below

When a patient file lists the address on one line, the import fills in the street, city, state and ZIP on the new chart, and tidies the ZIP to 62999-0001.

Why it matters: Addresses from your old system's export come across without retyping.

Text description of this video

The video has no sound and plays at half speed (66 seconds).

A patient file lists the home address on one line. After the import, the new chart shows the street, city, state and ZIP filled in, with the ZIP tidied to 62999-0001.
