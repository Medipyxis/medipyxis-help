How does Use last order fill the MRN?

whats-new Orders Updated 2026-11-25

Use last order copies the patient’s previous order of that type into a new draft. If that earlier order’s ID / MRN was empty, the new form fills the chart MRN.

The video has no sound, and a text description is below it. It was recorded with a made-up test patient; staff names and emails are blurred. It plays at half speed so the fields are easier to read.

What happens to the MRN when I use the last order?

No sound · 1 minute 5 seconds (half speed) · a text description of the video is below

The walkthrough starts from an earlier draft whose ID / MRN was empty, then uses Use last order. A new draft opens. A notice says dates, signatures, attestations and consents were cleared, and that wound measurements were copied from the last order and marked in red for review. On the new form, ID / MRN is already filled with the chart MRN. The form is left open and is not sent.

Why it matters: You can start from an earlier order without retyping the chart MRN, even when that earlier order never had one.

Text description of this video

The video has no sound and plays at half speed (1 minute 5 seconds).

A clinician is on Orders & DME, with one earlier draft order on the list. The Use last order caption points at that draft. They click Use last order. A new draft opens.

A green notice says dates, signatures, attestations and consents were cleared, and that wound measurements and assessment were copied from the last order. Copied fields that may need updating are marked in red. The clinician scrolls to Patient Information. ID / MRN is already filled with the chart MRN. A copied wound row is marked in red for review. The form is left open and is not sent.
